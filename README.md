# Suphakon Digital Lens — Portfolio 2026

Static portfolio website for **SUPHAKON SUKDAMRONGSAK** — UX/UI Design, Front-end and AI-oriented projects.

## What's included
- Light / dark theme with high-contrast dark mode and persistent preference
- Seamless, continuous marquee text inspired by modern portfolio homepages
- No cursor-based theme switching
- Interactive Profile board based on the portfolio source information
- Correct education GPA mapping from the supplied portfolio: **Nakhon Phanom Wittayakom School — 3.29** and **Suan Dusit University — 2.71**
- Interactive Skills tabs for Coding, Tools & Design, Language and Design Process
- Gentle 3D card tilt on desktop (disabled naturally for touch / reduced motion)
- Scroll reveal animations, active navigation state and responsive mobile navigation
- Project case-study modal galleries for all supplied project screens

## Run locally
Open `index.html` directly, or use any static server.

## GitHub Pages
1. Upload all files to a GitHub repository.
2. Go to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the main branch and `/root`.
5. Save.

No build step is required.
